# 问题与书网络的下一轮验证

状态：建议的试验计划，尚未执行。  
日期：2026-10-28

下一步优先做小规模样本扩展，同时验证真实使用。用新材料暴露问题，再针对问题精细化；暂不追求书籍数量或图谱规模。

## 当前已经有与仍然缺少的内容

已有三个正式 skill、一份 v0.4.0 草案、一个跨书提炼样例和可交互 HTML。HTML 中的 12 个问题与 8 个观点来自三本书的局部材料及作者访谈，并包含我们构造的应用场景。

尚缺：用户真实问题上的使用反馈、不同来源的相反回答、隔次检索的复用结果，以及旧版和草案处理相同任务的比较。漂亮的连线和可点击的页面不能替代这些证据。

## 先用已有材料完成一次真实探索

选一个用户近期确实需要判断的问题，并记录现象、目标、约束和当前打算。不要要求用户把问题改成适配某本书的样子。

用已有三本书中相关的材料尝试回答，允许得出“这本书帮不上忙”。记录：

- 找回了哪些观点，哪些关联原本看似合理但不能使用。
- 具体改变了哪个判断，或者新增了什么可以验证的不确定性。
- 还缺哪些信息；继续读书和直接观察现实，哪一个更能补上缺口。
- 最小下一步是什么；如果已经执行，结果如何。

如果连一次具体判断都无法推进，优先检查问题粒度、材料充分性和关联理由，再决定是否增加书籍。

## 再补两类有差异的材料

本轮以新增两本为试验规模，每本先选与问题相关的章节，提炼少量有出处的主张。数量是本轮范围，不是以后每本书都必须满足的配额。

| 样本类型 | 选择依据 | 要检验什么 |
|---|---|---|
| 新机制或新领域 | 对当前问题提供已有材料没有覆盖的解释，并有可核对原文 | 是否增加了可区分的解释，而不是换术语重复旧卡片 |
| 不同前提或不同结论 | 对相似问题提出不同做法；先核对材料再判断是否真的冲突 | 能否保存分歧、识别前提差异，而不是强行合成一致答案 |

可从用户已有书架选择，不必先购买新书。根据具体问题和可用材料确定书名；不要因为名气大就默认相关。若找不到真实冲突，不编造对立，保留“尚缺冲突样本”。

另有一个便宜的来源依赖检查：用《看得见的与看不见的》相关原文与《一课经济学》对照。后者序言已经说明思想承接关系；这一对适合验证“继承与扩展”的记录方式，不应被当成两个独立来源的重复证明。出处见[首次提炼样例](../../drafts/question-action-reading/examples/economics-thinking-pilot.md)。

## 每加一本书只提交实际增量

| 增量 | 记录内容 |
|---|---|
| 新问题 | 为什么已有问题无法容纳它；区别在目标、约束还是尺度 |
| 新方法 | 它比已有方法多解释了什么；出处与前提是什么 |
| 补强 | 新材料是否真正独立，还是转述同一来源 |
| 限定或冲突 | 哪一条旧连接需要收窄，或保留相反主张 |
| 没有新增 | 复用既有条目，不为了展示阅读量制造节点 |

每项都保留材料覆盖范围、作者主张与我们的关联判断。暂时无法核对的内容可以进入候选区，不能伪装成有原文支持的结论。

## 观察到什么，再精细化什么

| 实际遇到的问题 | 对应的小改动 |
|---|---|
| 换个问法就找不到已有问题 | 增加别名与具体场景，检查问题粒度 |
| 同名观点其实机制不同 | 拆分方法并保留不同作者的主张 |
| 所有观点都被泛泛连到所有问题 | 要求明确关联理由与至少一个不适用条件 |
| 加入不同意见后被错误合并 | 改进冲突与前提记录 |
| 内容更新要在多个地方重复修改 | 再把 HTML 示例数据抽成单一来源并生成展示；此时讨论导入导出与数据校验 |
| 找到观点却无法推进判断 | 补辨别信号、缺失证据或最小行动，不继续加概念 |

暂不为预想中的大规模使用引入图数据库、自动全书蒸馏或复杂分类体系。实际记录出现维护困难时，再处理对应问题。

## 本轮如何判断是否值得继续

保存原始请求、材料范围、实际输出与用户反馈。隔一次对话只读已保存记录，观察能否找回相关观点和原有反例。必要时对同一任务比较正式版与草案，使用[试用案例](../../drafts/question-action-reading/references/acceptance-cases.md)中的行为标准。

若用户能从真实问题找到有出处的回答、知道为什么选或不用某方法，并能复用既有记录，就继续扩展。若主要收益只是整理得更美观，先收缩结构、改进检索和关联质量。

本轮结束时只报告实际观察到的改善、失败和未解决项；未执行的实验继续标记未运行。知识内容的增加不自动触发 skill 正式版升级。
